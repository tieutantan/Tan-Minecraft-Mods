# Tan Gun

Tan Gun is a NeoForge mod for Minecraft 26.1.2 that adds an automatic piercing gun.

## Features

- Hold left click to fire automatically at 5 rounds per second.
- Firing does not use the vanilla item-use animation, so movement is not slowed.
- Each shot consumes one Iron Nugget from the player's inventory.
- Each living entity in the firing line takes 5 damage.
- Shots travel up to 100 blocks and stop at solid blocks.
- Empty ammunition prevents firing and plays a dry-fire sound.
- A short, sparse tracer points toward the first target hit and disappears quickly.
- The gun has a light visual recoil while firing.
- Creative mode does not consume Iron Nuggets.

## Build

Run from this directory:

```text
./gradlew build
```

The built jar is copied to the project root.
